# 墨页 · 产品设计 v0.1

## 定位

面向经常阅读技术文档、整理学习笔记、用纯文本写作的人，提供 iPhone、iPad、Mac 原生 Markdown 文件工作区。工作成果始终是一份用户可以移动、备份、用其他工具继续编辑的文件。

品牌暂定「墨页」，英文工程名 Markdown Reader。首版中文界面，最低支持 iOS / iPadOS 18、macOS 15。

## 核心体验

1. 打开应用，通过系统文档浏览器或 Mac 文件菜单新建、打开文件。可从系统文件提供器选择 iCloud Drive 等位置；应用不自建同步服务。
2. 默认进入阅读视图，展开大纲定位章节。新文件展示空状态，可开始写作或加载示例。
3. 切换编辑，直接修改 Markdown 源文。工具条围绕当前选区插入标题、加粗、斜体、任务、链接和代码。
4. 大屏进入并排模式，左侧源码、右侧预览。内容解析延迟 120ms，并丢弃过期结果。
5. 通过系统文档机制保存文件；已有文件可以调用系统分享。Mac 保留系统文件菜单与键盘快捷键。

## 信息架构

- 系统文件入口：新建、打开、最近使用文件，行为由操作系统提供。
- 大纲侧栏：品牌、当前文档标题层级、文件理念说明。
- 文档工作区：显示模式、查找、源码或原生预览、文档统计。
- 阅读设置：14–28 pt 字号、衬线字体、系统／浅色／深色外观，跨文档保留。

## 视觉规范

- 主色：森林绿（浅色 #336B58，深色 #7DBD9E）。只用于交互、引用线和完成状态。
- 背景：系统语义颜色，自动适配深色。避免把文件内容置于高对比装饰背景。
- 正文：默认系统字体 18 pt、7 pt 附加行距，内容最大宽度 740 pt。
- 标题：系统粗体；根据 Markdown 标题级别调整大小。
- 源码：系统等宽字体 15 pt，独立滚动区域。
- 代码／表格：12 pt 圆角，低对比底色，横向溢出时可以滚动。
- 图标：SF Symbols，图标按钮提供辅助功能标签或帮助文本。

## 设备适配

| 设备 | 交互重点 |
| --- | --- |
| iPhone | 单栏阅读／编辑；大纲通过系统导航展示；短状态栏适配窄屏 |
| iPad | 系统侧栏；工作区宽度达到 760 pt 时启用并排；支持硬件键盘 |
| Mac | 原生文档窗口、菜单、窗口缩放、侧栏、文本选区与键盘操作 |

切换到窄窗口时自动退出并排模式。大纲定位和搜索结果跳转使用源文件行号，与阅读块身份一致。

## 已实现的格式范围

ATX 标题、正文行、引用、无序／有序列表、任务列表、反引号或波浪线围栏代码、简单管道表格、分割线；行内强调、链接和代码由 Foundation AttributedString 解析。阅读中的任务按钮直接切换源文标记。查找按内容块计数、背景高亮，并支持下一处导航。

这是常用 Markdown 子集，不宣称完整 CommonMark / GFM 兼容。连续正文行目前各自渲染，嵌套列表、转义表格管道、Setext 标题、图片、HTML、数学公式、Mermaid、脚注尚未实现。未知块语法保留在源文中。

## 数据与异常处理

- 源文是唯一事实来源，预览与统计是派生数据；不创建内容数据库。
- 新文件使用 UTF-8；读取 UTF-8、带 BOM 的 UTF-8 和 UTF-16，保存保留编码类别。
- 无法解码的数据抛出系统文件读取错误，避免静默替换为乱码。
- UTF-16 保存可能规范化字节序；不保证字节级无变化。
- 任务切换保留 LF 或 CRLF。混合换行、无 BOM UTF-16 和传统编码不在本版保证范围。
- 保存权限、文件占用与文档冲突交给系统文档框架处理；尚需在实际云盘文件提供器中验证。
- 无遥测、广告、账号或应用服务器。
