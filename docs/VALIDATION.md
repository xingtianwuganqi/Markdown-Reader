# v0.1 验证记录

验证日期：2026-09-18。环境：Xcode 26.6 / Swift 6.3.3。

## 已通过

- macOS 通用构建（arm64、x86_64），未使用分发签名。
- iOS 通用设备构建（目标设备族 iPhone、iPad），未使用分发签名。
- Swift Package 核心测试 8 项全部通过：围栏代码与标题隔离、长围栏、任务 CRLF 往返、列表／表格、畸形表格、空输入／未闭合围栏、中文英文统计、非任务内容不变。
- Mac 实际应用打开临时示例 Markdown，检查真实深色阅读布局。
- Mac 切换并排视图，确认源码与阅读结果同时显示。
- Mac 点击阅读区任务项、保存，随后从磁盘读取确认 `[ ]` 已变为 `[x]`。
- Mac 选中源码文字后点击加粗工具，确认只给选区包裹 `**`，预览更新。

- Mac 中文查询「想法」返回 3 个匹配块，点击下一处切换到阅读并定位。

## 环境问题

沙箱首次阻止 Swift 模块缓存写入，改用 `/tmp` 缓存后测试通过。沙箱中的 iOS 资源编译无法访问 CoreSimulator 服务，在允许系统服务访问后重试构建成功。以上为环境权限问题，不是代码编译错误。

## 发布前仍需验证

- iPhone、iPad 模拟器及真机完整交互，软件键盘遮挡、分屏与旋转。
- 签名沙箱版本的文件授权、iCloud 文件提供器、外部编辑冲突及离线恢复。
- VoiceOver、动态字体、辅助功能大字号与窄屏长标题。
- UTF-8/UTF-16 真实文件往返、撤销／重做和崩溃恢复。
